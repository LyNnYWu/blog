# Lyndon Wu — Education, Research & Technology

Lyndon Wu 的公開個人部落格，使用 Hexo 建置並發布至 <https://lynnywu.github.io/blog/>。

## 內容主題

- 英文教學與考試設計
- 教育科技與工作流程自動化
- 研究方法與資料分析
- 專案管理與數位營運
- 交通安全、調查與證據推理

## 本機建置

```bash
npm ci
npm run clean
npm run build
npm run server
```

所有含日期的文章與清單皆採最新在前、最舊在後。內容與發布紀錄見 `docs/MEMO_blog.md`。
